# bitssh

类 Bitvise 的 SSH + 串口客户端，支持 Windows 与 Linux。终端、SFTP 双栏、端口转发、跳板机、串口调试、中英双语、主题与加密凭据。

A Bitvise-style SSH and serial client for Windows and Linux, with a terminal, dual-pane SFTP, port forwarding, jump hosts, serial debugging, zh/en UI, theming and an encrypted vault.
